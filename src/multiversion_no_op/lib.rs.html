19//! # `multiversion_no_op`
20//!
21//! This crate provides a pass-through function attribute called `multiversion`.
22//!
23//! The purpose of this crate is to optimize build times on targets that do not actually
24//! need multiversioning. That is, targets that need multiversioning can use the real
25//! [`multiversion`](https://crates.io/crates/multiversion) crate, and targets that do
26//! not need multiversioning can use this crate instead.
27//!
28//! This crate works in the `no_std` context.
29//!
30//! ## License
31//!
32//! Apache-2.0 OR MIT; the file named `COPYRIGHT`.
33//!
34//! ## Usage
35//!
36//! See [`encoding_rs`](https://github.com/hsivonen/encoding_rs/) crate for a usage example.
37
38use proc_macro::TokenStream;
39
40#[proc_macro_attribute]
41pub fn multiversion(_attr: TokenStream, item: TokenStream) -> TokenStream {
42    item
43}
